# Rules to check

Each line follows `RULING: <rule> | <what we did> | <why>`. The owner reconciles these in one sitting.
Status words in the "why" column: **Confirmed** (the rulebook or FAQ agrees), **Corrected** (a source
disagreed and the spec now follows it), **Unsourced** (the sources are silent; our ruling stands),
**Fan-source** (the value comes from a fan database or photo, not the rulebook).

Resolution pass (2026-10-10): lines now end `<status> (<citation>) [was: <old status>]`. **Still open** means the 2014 rulebook,
2020 rulebook, FAQ v1.1, the designer rulings digest (sources/bgg/official-rulings.txt) and The Long Night rulebook give no answer, so
our ruling stands. Citations: R = 2014 rulebook, F/FAQ = FAQ v1.1, digest = official-rulings.txt, TLN = The Long Night rulebook.
Summary and change list: docs/rulings-resolution.md.
